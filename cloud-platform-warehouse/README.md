# 仓库管理系统
## 1.仓库建模
### 1.1仓库管理
#### 仓库属性：
    仓库编码、仓库名称
    仓库类型（原料仓/成品仓/备件仓/线边仓/危化仓等）
    所属工厂/厂区、地址、楼层 
    负责人、联系电话
    仓库状态（启用/停用）
    温湿度要求、消防等级
    是否保税仓、是否冷链仓
    备注、排序号、删除标记
#### 按功能/用途分类：
    原材料仓、</br>
    半成品仓/在制品仓、</br>
    成品仓、备品备件仓、</br>
    辅料仓/耗材仓、</br>
    退货仓/不良品仓、</br>
    周转仓/临时仓、保税仓、</br>
    冷链仓；</br>
#### 按位置/管理模式分类：
     线边仓（产线旁边，直接供线生产，小批量高频补货）、</br>
     中央仓/主仓（集中存储，统一管理，向各线边/车间补货）、</br>
     区域仓/分厂仓（多工厂、多园区下的分仓库）</br>
     区域仓/分厂仓第三方仓（3PL仓，外包给物流公司管理的仓库）；</br>
#### 按库存管理性质：
     普通存货仓、</br>
     代管仓（存放客户或供应商委托物料）、</br>
     寄售仓（物料所有权属供应商，领用后才结算）、</br>
     呆滞料仓（长期不动用、待处理库存）；</br>
### 1.2库区管理
#### 库区属性：
    库区编码、库区名称、
    所属仓库（关联仓库ID）、
    库区类型（原料区/成品区/线边区/不良品区/待检区等）、
    库区位置（楼层、方位、车间号）、
    负责人、
    是否允许混放、是否批次管理
    是否支持盘点、是否可冻结
    先进先出策略（FIFO/FEFO）
    状态（启用/停用/ 维修）、删除标记
### 1.3货架管理
#### 货架属性：
    货架编码、货架名称
    所属仓库ID、所属库区ID
    货架类型（横梁式/贯通式/流利式/悬臂式/阁楼式）
    排/列编号（如 A 排、B 列）
    承重限制、层数
    存储品类限制（原料/成品/小件）
    是否允许混放、是否固定货架
    状态、删除标记
### 1.4库位管理
#### 库位属性：
    库位编码（如 A-01-02-03）
    所属仓库、库区、货架 ID
    库位坐标：排 - 列 - 层 - 位
    长/宽/高、承重、容积
    库位类型（整托盘位/散货位/拣选位/冻结位）
    可存放物料类型、是否允许混放
    是否良品位、是否锁定
    是否良品位、是否锁定
    库位容量、当前占用数量
    状态、删除标记
